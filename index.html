董事會級問題 · Board-Level Questions
三個必須先想清楚的問題
Q1AI PC 是新增市場，還是資料中心轉移？

主要是新增。AI PC 會分流一部分低階雲端推論，但會創造更多本機 agent、私有資料 RAG、創作 AI、離線 AI 使用。

Q2AI PC 會成為 CUDA 延伸，還是 Android 式硬體？

取決於端側 runtime。

Path A · CUDA 延伸開發者直接依賴 CUDA / TensorRT / NIM → NVIDIA 成為 AI PC 平台
Path B · Android 化被 Windows / ONNX / Copilot 抽象化 → NVIDIA 退化成可替換硬體供應商
Q3真正風險是什麼？

不是 AI PC 吃掉 Data Center，而是 NVIDIA 失去 AI runtime 控制權。

Kill Risk：若 Windows / Copilot / ONNX 成為唯一的 AI 抽象層，NVIDIA 將淪為可替換的零件供應商。

AI PC 不會殺死 NVIDIA 主機算力。真正風險是：Windows / Copilot / ONNX 把 CUDA 抽象化，讓 NVIDIA 變成第二個 IBM。

借 Windows 的通路，守 NVIDIA 的 runtime；開放 AI PC，導流 AI Factory。
